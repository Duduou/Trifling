# Trifling

**Trifling** is a 2D RPG project developed in **GameMaker Studio 2**. The original idea was to create a small but feature-rich RPG with a variety of equipment, enemies, environments, exploration, and combat mechanics.

Development is currently **on indefinite hold**, but the project contains several implemented systems and gameplay prototypes.

## Features

* 2D exploration and map transitions
* Equipment and inventory system
* Item collection and interaction
* Melee combat
* Enemy AI
* Dodge rolling
* Wall jumping
* Visual feedback when equipping equipment

## Controls

| Key         | Action           |

| **W A S D** | Movement         |
| **J**       | Attack / Confirm |
| **K**       | Back             |
| **Space**   | Jump             |
| **L**       | Roll             |

## Combat, Dodge, and Wall Jump

The combat prototype includes basic enemy AI, attacks, dodge rolling, and wall jumping.

The rat enemy uses simple behavior: it normally patrols back and forth, but will charge toward the player after being attacked.

The player can use the **roll** to avoid incoming attacks and the **wall jump** to climb vertical sections of the environment.

## Development Status

Development of Trifling is currently **on indefinite hold**.

The project was originally created earlier, and the executable was rebuilt in 2026. As a result, some compatibility issues and bugs have appeared between the original development environment and the current version.

### Known Issues

Some of the most noticeable issues are:

* The character death system is currently broken.
* The inventory can display incorrect item descriptions or quantities.
* Changing maps can cause inventory items to persist incorrectly.
* Resetting the game through the **Quit** option can also leave items in the player's inventory.

These issues are present in the current executable and are not representative of the intended final state of the game.

## Final Thoughts

Trifling was my **first game project**, and it became a major learning experience throughout its development. Working on it taught me a lot about programming, game development, and the challenges of turning an idea into a playable game.

Although development is currently on hold, I'm glad I had the opportunity to build it, as the experience and knowledge I gained from this project have been invaluable.
